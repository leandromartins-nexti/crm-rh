# One-pager do Problema

## Iniciativa
**Título:** Adicionar tela com gráficos do sistema  
**Descrição:** A proposta é desenvolver uma nova tela no CRM RH que apresente gráficos detalhados sobre o desempenho e a utilização do sistema, permitindo uma visão mais clara e intuitiva dos dados relevantes para a gestão de recursos humanos.  

## Produto
**Produto:** CRM RH  

## Problema
Atualmente, o CRM RH carece de uma interface visual que facilite a análise dos dados. A ausência de gráficos impede uma compreensão rápida e clara das métricas importantes, como taxa de retenção de funcionários, desempenho das contratações e satisfação dos colaboradores. Isso limita a capacidade da equipe de tomar decisões informadas e de identificar áreas que necessitam de melhorias.

### Impacto
- **Baixa eficiência nas tomadas de decisão:** Sem dados visualmente acessíveis, os gestores enfrentam dificuldades em avaliar o desempenho e as necessidades da equipe.
- **Perda de oportunidades:** A falta de uma análise rápida pode resultar em oportunidades perdidas para melhorar a retenção e satisfação dos colaboradores.
- **Dificuldade na comunicação de resultados:** Gráficos são ferramentas poderosas para comunicar resultados para stakeholders, e a ausência deles dificulta essa comunicação.

### Objetivos
- Desenvolver uma tela com gráficos que proporcionem visualizações compreensíveis dos dados do sistema.
- Melhorar a eficiência na tomada de decisões com base em dados visuais.
- Facilitar a comunicação de métricas e resultados para as partes interessadas.

## Soluções Propostas
- Criação de gráficos interativos que representem dados relevantes, incluindo:
  - **Gráfico de Pizza 1:** Taxa de retenção de funcionários
  - **Gráfico de Pizza 2:** Desempenho de contratações
  - **Gráfico de Pizza 3:** Satisfação dos colaboradores
- Implementação de filtros e opções de personalização para que os usuários possam adaptar as visualizações às suas necessidades.

## Próximos Passos
1. **Coletar requisitos detalhados com stakeholders:** Realizar reuniões para entender quais dados são mais relevantes.
2. **Desenvolver protótipos de tela:** Criar wireframes e protótipos iniciais para validação.
3. **Planejar a implementação:** Definir cronograma e recursos necessários para o desenvolvimento.

## Considerações Finais
A implementação desta tela com gráficos no CRM RH tem o potencial de transformar a forma como os dados são utilizados, promovendo uma cultura de decisões baseadas em dados e melhorando a eficiência da gestão de recursos humanos.
